# Anaya Wellness Spa — concept demo

A responsive, single-page website concept for presentation purposes.

## Preview locally
Open `index.html` in a browser. An internet connection is needed for the sample Unsplash photos.

## Before publishing
- This is an independent concept demo, not an official Anaya Wellness Spa website.
- Confirm permission to use the business name and branding.
- Confirm address, phone number, opening hours, treatment list, and all business details with the owner.
- Replace sample photos with owner-approved images.
- Do not present any sample content as verified customer reviews.
- The enquiry form currently opens a WhatsApp draft using the demo phone number; verify or replace it before use.
- Create a new GitHub repository for this project. Do not upload these files into the existing Bespoke City Exclusive repository.
